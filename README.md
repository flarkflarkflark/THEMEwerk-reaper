# THEMEwerk-reaper

A local REAPER theme browser for fast, searchable, and keyboard-friendly theme switching.

## v0.1 - Local Browser Prototype

This initial version focuses on local theme browsing and management.

### Features
- Lists themes from the REAPER `ColorThemes` directory.
- Apply a theme.
- Basic UI (details to be confirmed during implementation).

### Future Goals
- Search and filtering.
- Previous/Next theme navigation.
- Revert to previous theme.
- Favorites and recents.
- Enhanced UI with ReaImGui.
- Online theme browsing.
